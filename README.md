# Algorithm Arcade

1,000+ hands-on data structures & algorithms problems (Easy / Medium / Hard each), plus quiz modes.
Plain HTML/JS, no build step. Installable as an app and playable offline.

**Play:** https://ankitgupta5294.github.io/algorithm-arcade/

On your phone, open the link once, then *Add to Home Screen* (Safari: Share → Add to Home Screen; Chrome: ⋮ → Install app).
After that it works with no internet.

Source of truth: `dsa_game/` in the `ai_projects` repo.
